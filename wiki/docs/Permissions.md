# Quyền hạn {#permissions}

Đây là danh sách các node quyền của Slimefun.  
Hầu hết dùng cho lệnh, xem chi tiết tại trang [Lệnh](/Commands).

## Quyền liên quan đến lệnh {#permissions-for-commands}

| Lệnh | Mô tả | Mặc định |
| -------- | -------------------------| --------- |
| slimefun.cheat.items | Cho phép bạn dùng `/sf give` và `/sf cheat` | OP |
| slimefun.cheat.researches | Cho phép bạn dùng `/sf research` | OP |
| slimefun.stats.others | Cho phép bạn dùng `/sf stats` để truy vấn người khác | OP |
| slimefun.command.timings | Cho phép bạn dùng `/sf timings` | OP |
| slimefun.command.teleporter | Cho phép bạn dùng `/sf teleporter` | OP |
| slimefun.command.versions | Cho phép bạn dùng `/sf versions` | OP |
| slimefun.command.guide | Cho phép bạn dùng `/sf guide` | Mọi người |
| slimefun.command.search | Cho phép bạn dùng `/sf search` | Mọi người |
| slimefun.command.open_guide | Cho phép bạn dùng `/sf open_guide` | OP |
| slimefun.command.backpack | Cho phép bạn dùng `/sf backpack` | OP |
| slimefun.command.charge | Cho phép bạn dùng `/sf charge` | OP |
| slimefun.debugging | Cho phép bạn dùng `/sf debug_fish` | OP |

## Quyền liên quan đến khối {#permissions-for-blocks}

| Lệnh | Mô tả | Mặc định |
| -------- | -------------------------| --------- |
| slimefun.inventory.bypass | Cho phép bạn mở máy của người khác | OP |
| slimefun.cargo.bypass | Cho phép bạn dùng nút vận chuyển của người khác | OP |
| slimefun.gps.bypass | Cho phép bạn dùng thiết bị GPS của người khác | OP |
| slimefun.android.bypass | Cho phép bạn dùng robot của người khác | OP |
| slimefun.android.upload-script | Cho phép bạn tải lên script của robot | OP |
