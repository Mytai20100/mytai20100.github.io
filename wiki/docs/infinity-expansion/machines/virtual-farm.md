# Nông Trại Tự Động

Nông trại tự động là máy điện có thể trồng cây nông nghiệp hoàn toàn tự động.

Cho hạt giống vào ô nhập liệu là có thể bắt đầu hoạt động.

## Thông tin

Hiện tại nông trại tự động có 3 cấp độ.

| Cấp độ | Tốc độ | Tiêu thụ điện |
| ---- | --- | ------ |
| Cơ bản | 1x | 18 J/t |
| Cao cấp | 5x | 90 J/t |
| Vô hạn | 64x | 900 J/t |

## Sản phẩm

Bảng dưới đây liệt kê sản phẩm tương ứng với các loại hạt giống khác nhau, lấy công thức hiển thị trong hướng dẫn trong game làm chuẩn.

| Đầu vào | Đầu ra |
| ---- | --- |
| Mía | Mía * 2 |
| Tre | Tre * 6 |
| Hoa Chorus | Quả Chorus * 6 |
| Xương rồng | Xương rồng * 2 |
| Hạt lúa mì | Lúa mì * 2 |
| Hạt ca cao | Hạt ca cao * 2 |
| Hạt bí ngô | Bí ngô * 2 |
| Hạt dưa hấu | Dưa hấu * 2 |
| Mụn Nether | Mụn Nether * 2 |
| Cà rốt | Cà rốt  * 2 |
| Khoai tây | Khoai tây * 2 |
| Hạt củ dền | Củ dền * 2 |
