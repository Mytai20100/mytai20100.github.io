# Máy Phân Rã

Máy phân rã là máy có thể hoàn nguyên một số khối về vật liệu cơ bản.

## Thông tin

**Tiêu thụ điện**: 120 J/s

## Công thức

Bảng dưới đây liệt kê các công thức khả dụng của máy phân rã.

| Đầu vào | Đầu ra |
| ---- | --- |
| Khối ngọc lục bảo | Ngọc lục bảo * 9 |
| Khối vàng | Thỏi vàng * 9 |
| Khối sắt | Thỏi sắt * 9 |
| Khối Netherite | Thỏi Netherite * 9 |
| Khối Redstone | Bột Redstone * 9 |
| Khối thạch anh | Thạch anh Nether * 4 |
| Khối Lapis Lazuli | Lapis Lazuli * 9 |
| Khối than | Than * 9 |
| Đá nén bậc 5 | Đá nén bậc 4 * 8 |
| Đá nén bậc 4 | Đá nén bậc 3 * 8 |
| Đá nén bậc 3 | Đá nén bậc 2 * 8 |
| Đá nén bậc 2 | Đá nén bậc 1 * 8 |
| Đá nén bậc 1 | Đá cuội * 8 |
