# Hào quang thanh tẩy

Khi bạn dần thanh tẩy Nether, bạn có thể nhận được hiệu ứng tăng cường trong khu vực đã thanh tẩy.

## Cấp độ thanh tẩy yêu cầu

| Hiệu ứng | Yêu cầu giá trị thanh tẩy |
| --- | -------- |
| Hồi máu 1 | 500 |
| Hồi máu 2 | 1.500 |
| Hồi máu 3 | 2.500 |
| Hạt thanh tẩy 1 | 1.000 |
| Hạt thanh tẩy 2 | 2.000 |
| Hạt thanh tẩy 3 | 3.000 |
