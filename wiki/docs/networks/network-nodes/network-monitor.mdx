# Màn hình Mạng lưới

<ImageGallery images={[
  { src: '/images/networks/network-monitor.png', alt: 'Màn hình Mạng lưới' }
]} />

Màn hình Mạng lưới được dùng để kết nối ô lưu trữ liên kết với nó vào mạng lưới.

Sau khi nhấp chuột phải, bạn có thể mở giao diện lựa chọn để chọn khối kề bên ở hướng nào để kết nối.<br />
Sau khi chọn hướng, khối kề bên ở hướng đó có thể được truy cập thông qua mạng lưới.

Hiện tại Màn hình Mạng lưới hỗ trợ:

- [Vô hạn Tham lam - Ô lưu trữ](/infinity-expansion/storage)
- [Mạng lưới - Kho lưu trữ Lượng tử](../network-storage/quantum-storage)

Màn hình Mạng lưới là một khối mạng có thể chọn hướng, vì vậy bạn có thể dùng [Bộ Cấu hình Mạng lưới](../tools/network-configurator) để sao chép cài đặt hướng.
