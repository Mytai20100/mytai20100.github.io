# Máy Phát Điện Hạt

Máy Phát Điện Hạt có thể sử dụng hạt để phát điện.

Khuyến nghị nên [ngưng tụ](./quirp-annihilator) hạt trước rồi mới phát điện, sẽ kinh tế hơn.

## Thông tin

|  Hạt phát điện   | Thời gian duy trì |
| ---------- | --- |
| Hạt ngang (Up) | 1s |
| Hạt ngang (Down) | 1s |
| Hạt dọc (Left) | 1s |
| Hạt dọc (Right) | 1s |
| Hạt ngưng tụ | 8s |

**Hiệu suất phát điện**: 1536 J/s  
**Có thể lưu trữ**: 65536 J
