# Phần thưởng trao đổi gấp đôi

Khi cấp độ thanh tẩy tăng lên, Piglin không chỉ trở nên thân thiện mà còn có xác suất cho bạn phần thưởng trao đổi gấp đôi.

## Xác suất gấp đôi

`5 * (giá trị thanh tẩy / 750)%`

| Giá trị thanh tẩy | Xác suất |
| --- | -------- |
| 1000 | 6.66% |
| 2000 | 13.33% |
| 5000 | 33.33% |
