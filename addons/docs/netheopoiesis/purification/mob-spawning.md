# Sinh ra sinh vật

Khi bạn dần thanh tẩy Nether, bạn sẽ thu hút những sinh vật mới đến với thế giới này. Những sinh vật này sẽ sinh ra ngẫu nhiên ở những nơi có cấp độ thanh tẩy đủ cao.  
Việc sinh ra các sinh vật này độc lập với [thay thế sinh vật](./mob-swapping).

## Cấp độ thanh tẩy yêu cầu

| Sinh vật | Yêu cầu giá trị thanh tẩy |
| --- | -------- |
| Mực | 600 |
| Cá hồi | 600 |
| Cá tuyết | 600 |
| Cá nóc | 700 |
| Cá nhiệt đới | 1.000 |
| Axolotl | 1.000 |
| Thương nhân lang thang | 1.500 |
