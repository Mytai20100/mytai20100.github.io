# Trình Lấy Nguyên bản Mạng lưới

Trình Lấy Nguyên bản Mạng lưới có thể trích xuất vật phẩm từ khối nguyên bản kề bên.

Trình Lấy Nguyên bản Mạng lưới là một khối mạng có thể chọn hướng. Khối mục tiêu phải là khối nguyên bản và có kho vật phẩm.
Bạn có thể dùng [Bộ Cấu hình Mạng lưới](../tools/network-configurator) để sao chép cài đặt hướng.

Trình Lấy Nguyên bản Mạng lưới sẽ không tương tác trực tiếp với mạng lưới vì nó chạy trên luồng khác. Bạn phải sử dụng [Trình Lấy Mạng lưới](./network-grabber) để lấy vật phẩm trong khối đó.  

:::note

Trình Lấy Nguyên bản Mạng lưới chỉ hoạt động khi người đặt nó đang trực tuyến.

:::
